Download **AllStarsTextureStudio.exe** under Assets below. It is a portable Windows app: no manual archive unpacking, Python, or compiler required. Run it outside the game folder.

- Browse character and course textures directly from the original PC game.
- Recolor with hue, saturation, brightness, and a selected color range.
- Import/export images and copy sky textures between courses.
- Save editable projects, export mod ZIPs, and install/remove changes through the editor.
- Original game archives, saves, and settings are preserved; conflicting mods are checked.

**First preview:** local texture, project, install/restore, desktop, and native archive checks passed, as did the clean GitHub Windows build. A new in-game visual check of an exported recolor is still outstanding. Sky swaps do not change lighting, fog, or geometry. See [README](https://github.com/Demaunix/all-stars-texture-studio#readme) and [validation](https://github.com/Demaunix/all-stars-texture-studio/blob/main/VALIDATION.md) for compatibility and tested scope.

Windows 10/11 with .NET Framework 4.8 recommended. The EXE is unsigned. No original game assets are included.
